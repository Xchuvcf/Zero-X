# Zero X — IPTV Web Player

واجهة عربية RTL لمشغل ويب يعتمد على Xtream Codes-compatible API. المشروع ثابت (HTML/CSS/JavaScript) ويمكن استضافته مجانًا على GitHub Pages، ولا يحتاج إلى Node.js أو عملية build.

## الميزات الحالية

- تسجيل اتصال بسيرفر Xtream عبر رابط السيرفر واسم المستخدم وكلمة المرور.
- أقسام للقنوات المباشرة والأفلام والمسلسلات والمفضلة.
- تحميل التصنيفات أولًا ثم طلب عناصر التصنيف المحدد عند اختياره، بدل تنزيل المكتبة كاملة مباشرة.
- عرض تدريجي بواقع 48 بطاقة في المرة، وصور مؤجلة التحميل لتقليل ضغط الواجهة.
- بحث داخل العناصر المحمّلة حاليًا، وحفظ المفضلة محليًا لكل حساب/سيرفر.
- تشغيل HLS/M3U8 عبر hls.js، مع محاولة التشغيل الأصلي عندما يدعمه المتصفح، وصيغة بديلة قابلة للتجربة.
- نافذة مشغل تدعم ملء الشاشة وميزة صورة داخل صورة عندما يدعمها المتصفح، وعرض حلقات المسلسلات حسب الموسم.
- تصميم متجاوب مع الهواتف والأجهزة اللوحية والحاسوب، والوضع الأفقي للمشغل.

## النشر على GitHub Pages

1. أنشئ Repository جديدًا على GitHub.
2. ارفع `index.html` و`styles.css` و`app.js` و`README.md` إلى جذر المستودع.
3. افتح **Settings → Pages**.
4. ضمن **Build and deployment** اختر **Deploy from a branch**، ثم فرع `main` والمجلد `/ (root)`، وبعدها اضغط **Save**.
5. افتح الرابط الذي يعرضه GitHub Pages.

## متطلبات مهمة للتشغيل

- يجب أن يسمح سيرفر Xtream بالطلبات من المتصفح (CORS). إذا منع السيرفر CORS فلن يتمكن موقع ثابت من تجاوز ذلك بنفسه؛ ستحتاج إلى Backend/Proxy خاص بك وتتحكم في الوصول إليه.
- لأن GitHub Pages يعمل عادة عبر HTTPS، فإن لوحة Xtream التي لا تعمل إلا عبر HTTP قد تُحجب من المتصفح بسبب mixed content. الأفضل أن يوفر المزود HTTPS.
- متصفح الويب لا يشغّل كل صيغة فيديو. HLS/M3U8 مدعوم على المتصفحات المتوافقة؛ أما بعض صيغ TS أو MKV أو الترميزات الخاصة فقد لا تعمل، حتى لو كان الحساب صالحًا. دعم الصيغ تحدده صيغة البث والمتصفح والسيرفر.
- معظم واجهات Xtream ترجع كامل عناصر التصنيف الذي تطلبه في استجابة واحدة. المشروع يؤجل طلب التصنيفات والعناصر ويقسّم رسم البطاقات إلى دفعات، لكنه لا يستطيع فرض pagination على سيرفر لا يدعمها. التصنيفات الهائلة جدًا قد تبقى محدودة بسرعة استجابة السيرفر وذاكرة الجهاز.
- بيانات الدخول تُرسل مباشرة من المتصفح إلى سيرفر المزود، وتُحفظ مؤقتًا في `sessionStorage` للجلسة الحالية. لا تستضف موقعًا عامًا معدّلًا يجمع بيانات المستخدمين، ولا تدخل بيانات لا تملك إذنًا باستخدامها. المفضلة فقط تُحفظ في `localStorage` على جهازك.
- يعتمد المشروع على CDN خارجي لـ `hls.js` وخط Google Fonts. يمكن استبدالهما بملفات محلية إذا رغبت بالعمل دون CDN.

## بنية الملفات

- `index.html` — الواجهة.
- `styles.css` — التصميم المتجاوب.
- `app.js` — الاتصال بواجهة Xtream، تحميل التصنيفات، البحث، المفضلة والتشغيل.

## ملاحظات

هذا مشغل واجهة أمامية وليس مزود IPTV ولا يوفّر قنوات أو أفلامًا أو اشتراكات. استخدم فقط مصادر ومحتوى لديك صلاحية الوصول إليه.
