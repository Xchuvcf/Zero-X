# Zero X — M3U Playlist Player

واجهة ويب عربية متجاوبة مع الهاتف والحاسوب والتلفاز، مخصصة لاستيراد قوائم تشغيل M3U/M3U8 وتشغيل العناصر المتوافقة مع متصفحات الويب.

## الميزات

- إضافة رابط قائمة مرة واحدة وحفظه محليًا في المتصفح.
- فتح قائمة محفوظة لاحقًا بنقرة واحدة، وإعادة تسمية كل قائمة أو حذفها.
- دعم روابط `get.php?...type=m3u_plus&output=m3u8` وغيرها من روابط M3U/M3U8 التي ترجع نص قائمة صالحًا.
- قراءة القائمة تدريجيًا من تدفق الاستجابة لتجنب الاحتفاظ بنسختين نصيتين ضخمتين أثناء التحليل.
- استخراج الاسم والشعار و`group-title` من `#EXTINF`، وتصنيف تقريبي للقنوات والأفلام والمسلسلات حسب اسم المجموعة واسم العنصر وامتداد الرابط.
- بحث، ومجموعات، ومفضلة لكل قائمة، وعرض تدريجي للنتائج (48 عنصرًا لكل دفعة).
- استيراد ملف M3U محليًا عند عدم إمكانية جلب الرابط من المتصفح.
- مشغل HTML5 وHLS.js، وملء شاشة الموقع والمشغل، وصورة داخل صورة عندما يدعمها المتصفح.
- تصميم RTL مع حالات تركيز واضحة للتنقل عبر ريموت التلفاز أو لوحة المفاتيح.

## النشر على GitHub Pages

1. ارفع `index.html` و`styles.css` و`app.js` إلى جذر مستودع GitHub.
2. افتح **Settings → Pages**.
3. اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`، واحفظ.
4. افتح رابط GitHub Pages وأضف رابط قائمة M3U/M3U8.

لا يحتاج المشروع إلى خطوة بناء. مكتبة HLS.js والخطوط تُحمّل من CDN خارجي.

## حدود مهمة

- **GitHub Pages استضافة ثابتة:** لا يستطيع الموقع تجاوز CORS أو قيود المحتوى المختلط. إذا كانت الصفحة تعمل عبر HTTPS والرابط يستخدم HTTP، فقد يمنع المتصفح جلب القائمة أو تشغيل البث. يلزم رابط HTTPS متوافق، أو وسيط Backend تملكه وتؤمّنه. لا تستخدم وسيط CORS عام مع روابط تحتوي بيانات اشتراك.
- يجب أن يسمح سيرفر القائمة بطلبات المتصفح عبر CORS حتى يتمكن الموقع من قراءة النص وتحويله إلى عناصر. عند فشل ذلك، افتح الرابط للتنزيل ثم استورد ملف M3U محليًا.
- تصنيف القنوات والأفلام والمسلسلات تقريبي ويعتمد على `group-title` واسم العنصر وامتداده؛ قوائم M3U لا تقدّم دائمًا بيانات مواسم/حلقات منظمة مثل Xtream API، لذلك تظهر الحلقات كعناصر منفصلة.
- المتصفح لا يدعم كل الترميزات والصيغ. روابط TS المباشرة أو بعض صيغ MKV قد لا تعمل. HLS يحتاج إلى سيرفر متوافق وإتاحة طلب الملفات الفرعية.
- تتم قراءة القائمة تدريجيًا، لكن العناصر الناتجة تبقى في ذاكرة الصفحة لعرض البحث والتصنيفات؛ القوائم الهائلة جدًا قد تستهلك ذاكرة ملحوظة.

## الخصوصية

تُحفظ عناوين القوائم — بما فيها ما قد تتضمنه من بيانات دخول ضمن query string — في `localStorage` على المتصفح والجهاز الحاليين لعرضها لاحقًا. لا يرسل التطبيق تلك العناوين إلى خدمة Zero X منفصلة، لكن المتصفح أو امتداداته قد يصلان إلى التخزين. احذف القوائم من جهاز مشترك، ولا تستخدمه لحفظ اشتراكات لا تريد تخزينها محليًا.

## ملفات المشروع

- `index.html` — هيكل الواجهة.
- `styles.css` — التصميم والاستجابة للشاشات.
- `app.js` — إدارة القوائم وتحليل M3U والتشغيل.
